The Agentic Probe

The Instrument of Agentic Discovery & Engineering. AI agents collapse the software lifecycle into two phases; agentic probes (prototypes, simulations and possible futures) do the discovering.

💬 Chat with the paper

Ask your own AI agent about the paper: no account, no key. Paste this line once into a terminal (Claude Code), then start a new session (tools load when a session starts) and just ask, for example "Which SDLC models does the paper go through?" --scope user keeps it available in every project.

claude mcp add --scope user --transport http agentic-discovery https://research.longshore.fi/agentic-discovery/mcp

What is recorded: the authors want to know what readers ask, so that the paper can be improved. Only the question text is sent to them; nothing else is stored (no IP address, identity, answer or log). Your agent tells you this before the first search.

Other agents and options

Claude Desktop, Cursor, VS Code and other MCP clients: add this server URL (type HTTP / "custom connector"; some clients need a paid plan for connectors).

https://research.longshore.fi/agentic-discovery/mcp

No MCP support: have your agent call https://research.longshore.fi/agentic-discovery/search?q=<your question>&terms=<English keywords>, which returns the best passages as JSON (the question is forwarded the same way).
